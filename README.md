## Rise · Grow Taller (`grow/`)

Height and growth companion for Android/Samsung (installable web app, works offline).
Daily habit tracker, 6 guided workout routines with timer, food and nutrient tracker,
7-day meal plan, height/weight/sleep progress charts, genetic height estimate, and full settings.

Install on Samsung: open `grow/` in Chrome or Samsung Internet → menu → **Install app** / **Add page to → Home screen**.
